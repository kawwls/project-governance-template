# Locked Decisions

## LOCK-001
GitHub `main` is the approved source of truth for this project.

## LOCK-002
Implementation work must be performed on an approved task branch, not directly on `main`.

## LOCK-003
Antigravity is the implementation Executor only. It is not the Product Owner, Manager, Architect, or final reviewer.

## LOCK-004
Antigravity must not independently change approved requirements, architecture, business rules, schema/data contracts, security boundaries, public APIs, major UX flows, or core technology direction.

## LOCK-005
Antigravity must not merge into `main`, force push, rewrite published history, bypass review, or self-approve work.

## LOCK-006
Only the Product Owner or ChatGPT Manager may mark completed work `APPROVED_FOR_MERGE`.

## LOCK-007
Product-specific requirements, architecture decisions, and technology choices must be defined for each new project before implementation. This template intentionally does not impose a product or stack.
